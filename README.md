# Simple Interest Calculator

A simple script/tool to calculate simple interest based on principal, rate of interest, and time period.

## Formula
$$\text{Simple Interest (SI)} = \frac{P \times R \times T}{100}$$

Where:
* **P** = Principal amount
* **R** = Annual interest rate (in percentage)
* **T** = Time period (in years)

## Usage
Input the values for Principal ($P$), Rate ($R$), and Time ($T$) to calculate the total interest accumulated over the given period.
